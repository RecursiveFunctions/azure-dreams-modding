    What it actually edits
    
      
    
        Barry’s stock is built by a hardcoded routine that spells out each
        item byte by byte. Rewriting it as one immediate plus one store per entry
        fits nine items in the same instruction budget.
      
    
    
    
    
    
      
    Why the monster shop was easy
    
      
    
        Its overlay already carried a complete buy-side library — price
        lookup, gold deduction, inventory handoff — sitting unreferenced
        next to the sell code it mirrors. The patch wires it up rather than
        writing it.
      
    
    
    
    
    
      
    Nothing leaves this page
    
      
    
        There is no server. The file is read, modified and handed back by
        JavaScript running on your own machine, and every rewritten sector gets
        fresh EDC/ECC so the image stays valid.
